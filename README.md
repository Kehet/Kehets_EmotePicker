# Kehet's EmotePicker

_(beta quality - may not be stable)_

This addon adds a minimap button that opens an emote picker window.

The window lists all built-in emotes. Your most recently used emotes come first. The other emotes use the default order: emotes with a voice line come first and have a speaker icon. Inside each group, popular emotes come first and the rest follow in alphabetical order. Type in the search bar to filter the list. Click an emote to perform it. The window closes after you pick an emote.

## Usage

- Left-click the minimap button to open or close the picker.
- Drag the minimap button to move it around the minimap.
- Press Enter in the search bar to perform the first match.
- Tick "Require target" to only perform emotes when you have a target. Without a target, the addon prints an error to chat and the window stays open.
- Open the Statistics tab to see how many times you have used each emote.
- Press Escape to close the window.
- `/ep` or `/emotepicker` opens the picker.
- `/ep minimap` shows or hides the minimap button.

## Requirements

- World of Warcraft: Mists of Pandaria Classic
- The [Ace3](https://www.curseforge.com/wow/addons/ace3) addon
